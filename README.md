
# Bash Installer

A Bash project that automates the setup of a Python development environment.

## Features

- Detects macOS and Linux.
- Checks whether Python 3 is installed.
- Installs Python 3 if needed.
- Verifies pip availability.
- Installs Jupyter Notebook in a virtual environment.
- Runs Homebrew diagnostics on macOS.

## Requirements

- Bash
- Homebrew for macOS installations
- A Debian/Ubuntu-based system for Linux installation support

## Usage

Make the script executable:

    chmod +x env_install.sh

Run the script:

    ./env_install.sh

## Scripts

- `env_install.sh`: Python development environment setup.
- `install.sh`: Simple package installation example for Debian/Ubuntu.
